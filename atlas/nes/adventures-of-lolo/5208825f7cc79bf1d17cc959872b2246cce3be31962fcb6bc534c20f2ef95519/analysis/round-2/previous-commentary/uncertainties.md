# Round 1 semantic limits

All currently classified instructions and data have been reviewed. Unknown ranges remain the exact phase-1 complement (101 ranges, 23241 bytes), with boundary notes in source. Naming does not classify the ROM aliases in symbols.inc, prove table extents, or prove natural reachability.

- Shared zero page is heavily reused. `work_*`, scratch pointers and video destination/source aliases describe mechanical uses; their routine-local contracts take precedence. Scene animation also reuses object-array/player-coordinate RAM. Object kind/state names deliberately stop at encoded mechanics where the particular creature or game action remains unknown.
- Room source: ReadRoomRecordFromChr ($BA18; physical $3A28) selects CHR bank, PPU address and byte count by room index, reads through PPUDATA, then UnpackRoomGrid ($B44A; physical $345A) expands rows. The repeat loop emits an additional value at its shared literal exit. Output/source record bounds still depend on valid records; no full table or room-domain extent was newly classified. Redirect L006 should use these exact consumer mechanics and saved room0/24/49 evidence.
- Transfer engine: width>=height takes row traversal, width<height column traversal. The column path sets destination bit7 to request PPU increment32; this is not an input dimension flag. Source advances by width per column-row and one between columns in literal mode. The queued column body around $DB71..$DB92 remains unknown. Redirect L008 can use this clarified traversal without rejecting already supported positive rectangles.
- Audio: five effect slots and five music slots feed register shadow banks, arbitrated by effect masks and priority. Note and modulation interpreters share flow opcodes but have separate saved stack cursors. Descriptor/table ranges outside the map remain unknown. Legacy $4040/$4080/$4089 writes exist in this code but do not imply FDS expansion hardware on MMC1 or supported emulation of it. L007 remains a structural graph/extent question, not a claim that the unknown bank tail is all music.
- Stable JSR return assumptions still need per-callee contracts where structural discovery stopped (L005). Inline video/palette calls demonstrably skip two pointer bytes; NMI's menu escape deliberately resets the stack and abandons the interrupted chain. Neither should inherit an ordinary-return assumption.
- Ending motion is only partly classified. Velocity/position integration and pose progression have mechanical names; reunion identity/captures remain in the disassembly evidence. No terminal credits claim follows from the last castle image.

Source contracts document unresolved tails at their boundaries. Diminishing semantic certainty did not leave a source readability backlog. Whole-ROM classification and final editorial/archive acceptance remain separate.
