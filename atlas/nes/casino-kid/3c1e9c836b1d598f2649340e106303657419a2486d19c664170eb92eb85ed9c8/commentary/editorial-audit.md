# Final editorial audit (checkpoint pass-003)

## Scope and method
- Source: commentary/source/game.asm and ram.inc, generated by `tools/cmt.py build` from
  commentary/notes/*.ann. Edits were made in the notes only.
- Review credit: round 2 reviewed all 1582 scaffold entries (analysis/handoffs/round-2-commentary.md).
  That credit was reused. There was no whole-source reread.
- Material was revisited only where one of these targeted checks found a concrete inconsistency:
  1. block-comment headers ("Name: ...") whose name differs from the label that follows;
  2. CamelCase names in comments that are not defined as labels or equates (stale names);
  3. operands of the form `Label+N` with N >= 16, which point into a different, unlabelled table;
  4. raw absolute or immediate operands where a symbol is established;
  5. generic review.json summaries ("see the note above") and data tables with no description;
  6. adjacent duplicate comment blocks;
  7. `cmt.py todo`: 0 uncommented code spans.
- Lead L15 (analysis/leads.json; analysis/redirect/r2-a1/notes.md A-C) was applied.

## Findings and fixes
- **L15, password packing** (bank 5 PackMoneyAndProgress, bank 6 UnpackPasswordFields).
  - Added the 25-bit field layout: bits 0-24, 25-49 and 50-74 of PasswordBytes 0-9, with bytes
    10-13 verbatim.
  - Explained the OR merge.
  - Described the decoder's shift and mask.
- **L15, unread constants.**
  - BjDealerRecordTable +10 and PkOpponentTriples +0 are now described as constant fields with
    no reader.
  - Their meaning is stated as unknown. This replaces "not interpreted" and "role open".
- **L15, blackjack codes.**
  - BjCompareHands now cites the explicit writers of codes 1, 2 and 3.
  - Correction to the redirect note: code 3 is written by BlackjackSession ($8052, dealer-only
    blackjack after the deal), not by BjSettleHand. That instruction now has an end-of-line
    comment.
- **Label+offset aliases (16 new data labels).** These operands now name the table they read:
  - TitleCursorPositions+4/+10/+198 became TitleFlashPtrsB, TitleFlashPtrsA and
    TitleMenuFramePtrs.
  - TitleSpriteFrames+56 became TitleSpriteFrames2.
  - SceneNametableIds+3/+21 became SceneChrSets and ScenePaletteIds.
  - BrokeText+104/+184/+233 became PasswordGridDesc (+2), PasswordMessagePtrs and
    PwMessageFramePtrs. The PasswordEntry descriptor immediates are now
    `#<PasswordGridDesc` / `#>PasswordGridDesc`.
  - CursorKind+26/+36/+62/+72/+77 became CursorDescAddrs, CursorOamSlots, CursorTilePtrs,
    CursorSizes and CursorAttrs.
  - BetCursorPtrs+61/+199 became BetAmountPtrs and BetTierTable.
- **RAM alias.** MenuCursorPos was declared as 16 bytes, but it is indexed by cursor kind (0-4).
  It is now 10 bytes, so $0060-$0065 resolve to their existing names: PortraitAnimId,
  PortraitAnimFlags, MouthFrame, MouthFrameSaved, MouthTimer and EyeFrame. Before this change,
  the portrait animation code read as MenuCursorPos+10..+15.
- **Raw operands.**
  - The bank-select immediates at $E646, $E768 and $E80C now use BANK_TITLE / BANK_BLACKJACK.
  - The three uncommented cross-bank calls (bank 6 $8019 MusicCommand and $801C MusicUpdate)
    and the $0F home-bank value now have comments.
- **Header and label mismatches.** The comment headers "Showdown" and "RunNmiTaskTwice" now
  read PokerShowdown and RunNmiTaskAndWait.
- **Stale prose names.** These names in comments were replaced with the real names:
  - NpcWalkTriggers, NpcCanWalk and NpcTurnTable → PeopleWalkChance, the PeopleTriggerPtr list
    and PeopleTurnTable. The walk condition was also corrected to match the code.
  - EncounterTexts → EncounterTextPtrs.
  - BetStepValues → BetAmountPtrs.
  - TitleFlashFrames / TitleMenuFrames → the new pointer labels.
  - CursorSpriteDescPtrs → CursorDescAddrs.
  - "PlayerSecondBet", which named no routine, is now an honest unknown-bytes note before
    OpponentSecondTurn.
  - "SendStruct" → EndingSendStruct.
- **Undescribed tables.** Added notes for BjSplitCursorPos, BrokeTextParams, BrokeText,
  PwSpriteTemplate, MouthTileTable, EyeTileTable and WipeTileTable.
- **Review inventory.** tools/cmtreview.py now writes the summary of a data table that has no
  note of its own from its consumer's comment, and adds that comment's source line. As a
  result, no region or unit keeps the generic "see the note above" summary.
  - Units went from 1419 to 1435 (the new data labels).
  - All entries and units are reviewed.

## Accepted as is
- 367 "inline parameters" region summaries. These are structural notes next to their callers.
- "Continuation of X" and "Entry label inside X" unit summaries. Each one points to the
  documented owning routine.
- Repeated per-region default notes for consecutive generic graphics, screen and vector-copy
  blocks (DN). These are boundary notes, which the policy allows for generic data.
- The raw `jmp/jsr $8010-$801C` cross-bank entry slots, which have comments, and the
  `inc $8001` reset idiom.
