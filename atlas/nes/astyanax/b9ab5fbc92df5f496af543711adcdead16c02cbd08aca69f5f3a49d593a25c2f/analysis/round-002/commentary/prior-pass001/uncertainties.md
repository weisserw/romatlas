This does not establish every called handler's return-bank contract. Redirect should follow the supported handlers and compare each bank shadow/mapper write against its callers (existing R001-CALL-CONTEXT).
- Scene dispatch: physical $005CC0–$005D43 and $007801–$007828 uses state-indexed word pointers. The supported loop, dialogue waits, scroll/palette events and existing ending observations are explained. Table domains and every state transition remain unclassified where the map says unknown. Follow the consumer and supported state mutations (R001-INDIRECT).
- Audio: physical $018D05–$019136 explains priority/channel arbitration, duration counters, timer writes, stream control and envelope phases. The indirect command table at CPU $8F3A and all handlers are not fully classified. Fetch/store mechanics support the names, while musical intent and complete opcode domains remain unresolved. Do not infer a complete audio format from the classified handlers alone (R001-INDIRECT).
- Level data: physical $01F445 onward decodes the 21-byte stage descriptor, metatile sources, palette thresholds, collision storage and transfer strips. Exact unclassified table bounds/record formats in switched resource banks remain redirect work (R001-LEVEL-DATA). RAM resource pointers are named by their supported consumers, not guessed asset contents.
- Actor species and game-specific meter/action meanings remain tentative. Source uses actor variant, primary/secondary meter and attached weapon mechanics instead of assigning unsupported monster names or resource names. The attached object's relative pose, rendering and hitbox contact are established; exact animation associations are unresolved.
- Scratch bytes are reused among pointer/arithmetic/rendering helpers. Neutral Scratch18 etc. aliases do not claim persistent variables. Persistent player/actor fields and hardware registers have descriptive aliases where consumer semantics support them. Audio array names reflect selected-channel indexing; callers still supply the proper X/Y and carry contracts.
- Text $FB calls CPU $E692, whose continuation is unclassified. Other classified controls explain completion, cursor reset and timed pause. The declared Text region's encoding remains unresolved; it is not claimed to be ASCII.
- Uniform PRG blocks retain the disassembly boundary/reference checks and generic non-code role. They are not called padding. CHR is described as two-plane 8x8 tile storage; tile game roles and all runtime bank combinations are not inferred.
- All 225 unknown physical intervals remain opaque with explicit boundary notes. Exact residual ranges remain in analysis/round-001/unknown-complement.json. No code/data role has been invented for them.
