## Round 3 commentary pass (2026-11-21)

### How the source is produced
- `source/game.asm` is generated by `tools/build.py` from the frozen `before/game.asm`
  plus `tools/notes.txt` (round 1), `tools/notes2.txt` (round 2) and `tools/notes3.txt`
  (round 3), loaded in that order.  Bytes are never changed; only labels, symbolic
  operands with the same values and comments are added.
- `tools/review.py` fills review.json from the build's units.json.  The scaffold is
  kept intact, and the four L-020 fragments get explicit unit records.
- Edit cycle: notes*.txt -> `python3 tools/build.py` -> `python3 tools/review.py` ->
  `commentary.py verify` -> `commentary.py read`.
