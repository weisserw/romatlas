## Round 1 commentary pass (2026-11-21)

### How the source is produced
- `source/game.asm` is generated by `tools/build.py` from the frozen `before/game.asm`
  plus the hand-written annotation file `tools/notes.txt` (symbols, routine names and
  headers, block/line comments, data labels, unknown-gap notes).  Bytes are never
  changed; every label/symbol restates the same value, and `commentary.py verify` is
  the fidelity check.  Helpers: `tools/model.py` (parser), `tools/consts.py`
  (symbolic immediates), `tools/review.py` (fills review.json from `tools/units.json`),
  `tools/show.sh`/`tools/addr.sh` (compact listings for reading).
- To edit: change `tools/notes.txt`, run `python3 tools/build.py`, `python3
  tools/review.py`, then verify and read.  (Direct edits to source/game.asm would be
  lost on the next build; if switching to direct editing, stop using build.py.)

### What was added
- Symbols: hardware registers, MMC1 serial ports, ~150 RAM variables (zero page,
  OAM/screen/sound buffers) with bank-scoped meanings where zero page is reused, ball
  record field offsets (BALL_*), state values (BST_*), and constants for game modes,
  player flags, buttons, fade flags, demo modes, PRG banks.
- Every routine named (no address-only routine names remain); branch targets use
  `<Routine>_Loop/_Skip/_Return` names or explicit names in key routines.
- FarCall targets resolved symbolically (`#<Far_X/#>Far_X`, PRG_* bank constants);
  bank-entry JMP slots in unknown bytes get CPU-valued labels with notes.
- String/screen/palette/metatile/sprite-grid pointer immediates replaced with labels
  (`Str_*` named from the text where possible); ~90 referenced tables labelled.
- Header comments for all routines; block comments in MainLoop, NMI, rules, shot input,
  trial-shot simulation and ball movement.  Text regions show their decoded text.
