# Round01 commentary uncertainties and redirect contracts

Current-source readability is complete; these are unresolved interpretations and structural investigations, not skipped source review. All 704 classified fragments and 207 exact unknown gaps are explained. Source labels below live in commentary/source/game.asm. Existing maps and classification are unchanged. Physical offsets include the 16-byte iNES header.

The working-map/event consumers need distinct contracts. Earlier disassembly handoff grouped C816/C877/C8A8 as event consumers; source review narrows that premise:

- `ApplyAreaMapPatchList` / C806, physical $01C816, selects mapper bank value 3 (effective lower PRG banks 6/7) and descriptor $801A or $801C according to $02CA. It resolves AreaNumber, then consumes index/value pairs, writing PRG RAM $7E00[index], until $FF.
- `FindCurrentCellRestrictions` / C85D, physical $01C86D, reads bank-selector-3 descriptor $801E. Two-byte records are packed XY then restriction flags; X is the high nibble and Y the low. C877 is its coordinate comparison loop. A match updates $02BB. This does not by itself establish an event trigger or list extent.
- `DispatchFieldFacingOrMovement` / C8A8, physical $01C8B8, interprets controller directions. C8E3 moves with facing-specific restrictions and wraps coordinates on a 16 by 16 grid. It is not an event list decoder.
- `FindAreaEventRecord` / D029, physical $01D039, uses mapper selector 1 (effective lower banks 2/3), descriptor $8016 and AreaNumber. Three-byte records contain packed XY, handler selector, payload. $FF terminates. Matching returns X=selector and $02E0=payload. D07F optionally clears a working-map nibble when selector bit 7 is set, then uses low seven bits to dispatch through D0A3. `$02DF` identifies the byte/nibble previously sampled. Exact table bounds, selector domain, boss/ending record and full handler effects remain unproved.

Redirect should inspect area15's actual three-byte event list and its selected handler/payload, then compare the saved transition15 state's coordinates/working map. The prior coordinate hypothesis only rejected its attempted recipe; it does not reject boss/event structure. Do not require natural reachability to establish a separately supported record structure.

`GenerateCartridgeRamHandlers`, physical $0114B3 / CPU $94A3 under effective banks 8/9/14/15, constructs executable work at $72D7/$7462/$771F using templates, parameters and six-byte replicated groups, appending RTS. Template lengths come from $95E3/$95E5, replication counts from constants, and $9579 adjusts embedded addresses using $03C8. This is stronger upload-origin groundwork than RAM fetches alone, but ROM template boundaries and destination lineage still need independent inspection before classification. The NMI source clearly explains each pending-handler flag and busy wait.

`CopyAudioResourceIntoPrgRam`, physical $01EC27 / CPU EC17, resolves a table pointer through mapper-selector-2 descriptor $8014 and copies exactly 840 bytes to $6BD0..$6F17. X starts $48, decrements per byte and wraps three more times under outer count four; it does not count pages. Y wraps advance both pointer high bytes. Redirect may resolve selected immutable source records and inspect these exact spans. Do not infer all audio tables or sample data boundaries from one selection.

`ExpandCompressedPatternStreams` D42D emits 32 blocks of 64 pattern bytes from a control stream and separate literals. Two-bit pairs select 0/$FF/$FE/literal. Source $8n except $8C repeats synthetic control $FF (literal pairs); source $FF repeats synthetic zero. `ExpandBinaryMapLayer` EB1E separately expands binary bits into packed nibble cells, and `ExpandSparseMapBytes` D4FF uses mask-controlled zero/literal bytes. These distinct formats provide useful local consumers; complete table extents and unused mixed-bank intervals remain unknown.
