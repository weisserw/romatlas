This is redirect evidence, not an applied classification. All proposals use Static provenance. Native execution and natural selector domains remain separate claims.

The first entry saves shadow 33, calls D646 to select the area-data page, draws three paired rows beginning at index 40, redraws the top border and cursor, restores 33 and tail-jumps to FBAD. ## Action records and the bank 0 callback table

Physical bank 2:AA83 contains 43 repeated seven-byte records. They agree with the independently accepted copy-seven consumer and callback fields 5/6; 23 sparse records were already accepted. Additional callbacks have ordinary action-field, actor-state and return contracts and were followed in this pass. The last record's high callback byte at ABAF overlaps biased mapping cell zero. No complete global mapping-selector domain is claimed. Adjacent mapping, mask, packed numeric and signed/quantized rows remain composite Data, bounded by known AD84 native code. A5A6 has 49 explicit item IDs; A73E/A742 have four masks and four paired parameters. Inventory segment boundaries, finite masks and six attribute thresholds were inspected as well.

Bank 1:A3F8 loads 00/01 from bank 0 split origins 8ADA/8B69 indexed by 724F. A6F9 calls the property reader but does not change 00/01. A40D calls A413, which jumps through that pointer. This is a typed native callback consumer. The biased payload occupies 8ADB..8B6A and 8B6A..8BF9: 143 structural entries, 102 distinct targets. All targets were followed under their supported static entry contracts; no conflicting existing Data or instruction starts appeared. Index zero, whose bytes overlap the preceding possible RTS and the last low byte, is not proposed. This does not assert that every index is produced or reachable.

An explicit X=18 caller independently bounds the first 18 zero-delimited ID lists at 8BF9 through physical terminator 3227. They contain 90 distinct IDs. Exactly 147 list bytes are proposed. An attempted extension toward the first callback at 8CAE was rejected locally because the connected helper at 8C93 is native. This counterexample rejects that extension, not the supported 18-list prefix or the callback table.

## Generic Data and Text

Supported generic non-code proposals include physical 17's suffix, banks 18/19/24/26/27, the lower 54 prefix, bank 53's remaining frontend payload, and bank 60's numeric prefix. Existing classifications are preserved. This is a code-versus-data claim, not a complete graphics, map, character or audio schema.

Bank 53 has frontend pointers, strings, descriptors and numeric/control packets, with real bank-56 consumers. The sole apparent control hit, 55:8F3E -> 53:A275, is the documented stale context: 98E0 explicitly maps physical 2 first. It does not conflict with bank 53 Data. Other compact sex/class/alignment/attribute display fields use Text where their framing is clear. Mixed descriptors and numeric/encoded strings remain composite Data with honest schema uncertainty.

Remaining pure referenced components were checked against exact current/new native boundaries and saved in data-primary.json. These include repeated thresholds and packed fields in bank 1; PPU/OAM/CHR and tile/attribute rows in bank 50; coordinate/mask/layout tables in banks 52/55/56/57/58/59; and regular RAM-pointer arrays and display descriptors in fixed banks. Large native-looking components in 0/1/50/63 were split; none was classified merely because a reference entered it. ## Bounded byte sequence

Bank 60:90ED loads byte index 7F57, increments that byte, reads 90F7,Y and returns. The address domain is exactly 256 bytes despite an unbounded number of calls. Every byte in 90F7..91F7 is 1..20; the following FF region supplies an independent endpoint. The bank-52 action-threshold caller treats 1 and 20 as endpoints. This supports the complete generic Data interval independently of a full-cycle runtime observation, uniform probability or an original random generator model. The earlier lack-of-extent premise was too strong for this byte-indexed representation.
