Source: https://gamefaqs.gamespot.com/nes/587098-athletic-world/faqs/53464 (search excerpt consulted 2026-11-06). Training, Beginner, Expert courses; normal controller selects menus, floor mat controls events. Other search results identify five events; local menu confirms Hurdles, Animal Trail, Dark Tunnel, Hop a Log, Rafting. External controls remain hypotheses until tested locally.

Confirmed local route: blank input until title, Start held 2 frames then released -> training event menu; another 2-frame Start press/release -> Hurdles. Title snapshot at frame 54; event-menu snapshot at frame 96. Event selection RAM $032C, bounded to 0..4 by CPU $826D-$8280; mode copied into $0328 (0 training, 1 beginner, 2 expert) from $A4 at CPU $81E2-$81E7. $2C is menu progression substate; $A1 selects screen record. Mat decoder reads port 2 bits 3/4 ($4017) into $0326; standard emulator inputs cannot drive those documented unsupported peripheral bits.

Investigating five event selector shortcuts from the initialized training menu. Patches only RAM, not ROM. All resulting execution is artificial, with actual frame output and instruction coverage required before claiming a visit.
