## Workflow (local tooling, commentary/tools)

source/*.asm is generated by `python3 commentary/tools/build.py --dump` from the frozen
listing (before/game.asm) plus the annotation database (annotations/*.ann: names,
block/line comments, RAM syms, constants, word tables).  Edit annotations, rebuild,
then run `commentary.py verify`.  Helpers: check.py (every annotation lands in
source), todo.py (auto-named labels per bank), nohead.py (routines without block
comments), regioncheck.py (unexplained Unknown/Data ranges), review.py (fills
review.json), view.py/view2.py/summ.py/bytes.py (reading aids).
Round 1 build changes: annotated cheap locals used across scopes are promoted to
globals; code resuming after inline arguments is left unlabelled unless referenced;
`const`/`imm` annotations plus automatic STATE_*/PAD_* immediates; automatic notes for
inline-argument blocks and short Unknown tables.
