# Investigation ledger

## Round 1 / disassembly pass 1 (checkpoint pass-001)

ROM: Battletoads & Double Dragon (Rare 1993), AxROM, 8 x 32 KiB PRG banks (file
$00010 + bank*$8000), CHR RAM. Context for bank b is prg_banks [4b,4b+1,4b+2,4b+3].

### Architecture findings (static, from ROM bytes)
- All banks share a top-of-bank stub layout: NMI $FF98 (saves A/X, writes X=0 to
  $FFB3 -> bank 0, continues at bank 0 $FFA3 jmp $FE05), NMI exit $FFA6 (restores
  bank $35 via sta $FFB3,y), far call $FFCB (lda #0 / ora #thisbank -> $34, push $13,
  stx $13, switch to bank Y, jsr $8000 -> jmp ($0013) with $14=$80, i.e. a JMP slot
  at $80xx in the target bank, then switch back), delay loop $FFEB, RESET $FFF2
  (select bank 0, jmp $8291 in bank 0).
- $FFB3-$FFCA in every bank = bus-conflict bank-select table (byte n = n).
- Each bank has a JMP vector table from $8003 (stride 3) reached through the far call.
- Bank 0 is the main/NMI bank; RAM $10 = stage id; main thread continuation at
  $2A/$2B set by $85CF and resumed by jmp ($002A) at the end of NMI.
- Bank 3 holds the sound driver (writes $4000,x; command table $8FF2).

### Method
1. Observed coverage: romatlas trace aggregates (analysis.contexts) harvested to
   traces/round01/coverage-contexts.json (natural startup/menus/intro/stage 1 plus
   artificial $10 stage patches; broken $01/$07 runs excluded).
2. Static recursive descent (analysis/tools/round01/rd.py, build.py) per bank from
   vectors, JMP-table slots, stub entry points, observed roots and the bounded
   dispatch tables in tables.py. Rules: follow branches/JMP/JSR; continue after JSR
   unless the callee pops the return address (none found in the 16-insn scan);
   stop at RTS/RTI/indirect JMP/bank-select stores ($FFB3 writes) and RAM targets;
   reject a root's whole closure if it reaches BRK/KIL/unofficial opcodes,
   except that a conditional branch whose fall-through decodes into invalid bytes is
   treated as always taken (complementary-branch pairs and lda #imm + bne/beq/bpl/bmi
   are recognised exactly; heuristic prunes logged: bank 0 $B45D, $B9CA, bank 2
   $FC92). Unions are checked for overlapping instruction boundaries (none).
   Why not analysis.discover_context: see toolkit-issues TK-002.
3. map generated by analysis/tools/round01/mkmap.py, loaded with map.load,
   map.validate ok, saved/exported, checkpoint pass-001 byte-identical.

### Data classified (Static)
- iNES header; per-bank vectors $FFFA-$FFFF; per-bank $FFB3 bank-select table.
- Dispatch/pointer tables with consumer + independent end: bank 0 $D2C6 (31 words),
  bank 1 $8094 (4), bank 7 $815C (4), bank 3 $8FF2 (84, sound commands), bank 6 $9002
  and $901E (14 each), bank 6 $903A-$9058 stage-order byte tables, bank 6 $997E (10).
  All table targets decode cleanly and were added as code roots.
- Uniform $00/$FF runs >= 32 bytes with no instruction claims (bank 3 $FF2E, bank 5
  $A4EF/$BC47/$BCD7/$C8CD/$C917/$D509, bank 6 $A716/$FF50).

### Rejected roots (left unknown)
- Bank 3 JMP slot $8024 (jmp $8FF2 -> pointer table), bank 6 slot $800C (jmp $A4F6 ->
  BRK), IRQ vectors bank 3 ($FF2E padding) and bank 6 ($FE30 -> BRK). Lead L-004.

### Remaining unknowns
213,664 bytes, dominated by graphics/level/compressed data (no long padding).
See leads L-001..L-009 in analysis/leads.json.

## Round 1 / redirect (attempt r01-a1, checkpoint pass-001)

Research directory: analysis/redirect/r01-a1/ (read-only helpers lib.py, closure.py,

Findings (static unless noted):
- Bank 0 ObjTypeHandlers $9A71: 92 words ($00-$5B); entry $5C would be $1111 and
  $9B29 is an independent table base -> extent proven. 62 unknown targets decode
  cleanly: +10,278 code bytes with the corrected rule that jsr $DFCF returns (it is a
  conditional pla/pla/jmp $EE43 abort; the round-1 16-insn pop scan misclassified it).
- Bank 6 UpdateBackgroundObjects table $9C4E: 41 words ending at first target $9CA0;
  +2,077 code bytes. Same-bank bank-select stores (value n&7 == current bank, e.g.
  lda #$16 / sta $FFC9 in bank 6) only toggle the nametable bit; continuing after them
  adds 122 (bank 2) + 330 (bank 6) bytes. rd.py stopped at all such stores.
- CHR decompressors (banks 1, 7) and bank 4 RLE loader: formats decoded; static
  emulation bounds set tables, headers and streams (~81 KB). 255-tile loads overrun
  into following streams; bank 4 set $0E points at code (invalid); bank 1 set $34
  stream ends at 160 tiles = $FF5B before IRQ RTI $FF5C.
- RAM routine $0782-$07FF = bank 7 $805F-$80DC (copier $8041). Runtime check (natural
  stage-1 load from snap_lvset, 300 frames): 110/126 bytes equal; the 16 different
  bytes are exactly the ldy operand lows at $0796+6k patched by bank 2 $FDF4/$FDFA.
- Bank 2 = raw 256-byte player/character frame windows (pointer table $FE07-$FF68,
  177 words) uploaded by that RAM routine; windows cover $8030-$EF2F contiguously.
- Banks 3/4/5/6 remaining large gaps: consumers identified (sound tables/scripts,
  tile upload tables, decoder trees, spawn lists, anim scripts; screen descriptors;
  stage map bases $A4D5/$A4E2; metasprite tables; text with bit-7 terminators).
  jsr/jmp-to-known-entry pattern density 0-1.5/KB vs code-like gaps (bank 5 $B353
  26.8/KB, flagged as code in L-019).
- Ledger after the proposed batch: ~11.2 KB unknown remains (mostly small
  consumer-referenced tables in banks 0/2/4/5/6, stub tails, see ledger.py output).
- Gameplay (artificial state edit, natural transitions): $DA=$FF triggers the stage-end
  path; order $03,$05,$02,$04,$08,$09,$06 then $0B ending text. Stage table $903A is
  indexed by level number. "$08 = title/attract" (round 1) is contradicted.

Negative/method results:
- Range-filtered ROM Read streams work but trace mode runs ~4 fps (300 frames 74 s vs
  6 s plain); unfiltered Read includes opcode/operand bus reads (7.2M events / 120
  frames). Broad runtime data-read coverage was therefore not pursued.
- $0600/$068C/$0532/$0700-$072F RAM code/data are runtime-built; no single ROM image.
- No RTS-trick (pha/pha/rts) dispatch exists in classified code.
