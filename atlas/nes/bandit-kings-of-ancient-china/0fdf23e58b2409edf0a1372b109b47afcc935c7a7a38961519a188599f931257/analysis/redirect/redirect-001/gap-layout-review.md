# Script-adjacent residual review

`residual-triage.json` freezes the230 exact hypothetical residual segments after
asset proposals (14085 bytes), separate from accepted unknown198358. Every large
mixed interval was rendered in64-byte lines and inspected through its end. Exact
full bytes are retained in gap-layouts.json; isolated text/control proofs are in
gap-text.json. These are generic Data, not speculative full string-object extents.

The intervals contain recurring NUL-delimited English words/printf formatting,
ESC commands already adjoining accepted Text, short little-endian origin arrays,
small word-valued game tables, repeated tile borders and limited-alphabet grids.
`gap-text.py` uses whole-interval alphabet plus meaningful-word evidence, never a
sample-only prefix. `gap-layouts.py` records remaining whole mixed objects after
inspection; a generic Data claim does not assert that all origins are callable,
all referenced strings are naturally displayed, or one particular table stride
covers a whole interval. Some origins point to VM representations; this is data
containing code references, not proof that origin bytes themselves are native code.
Bank7 19F6:1B9A contains repeated multibyte diagnostic strings with ASCII printf
fields; exact character encoding is unresolved and is not needed for generic Data.
Bank15 1705:176D is a0..48 word permutation plus three message origins. Bank16
1DC4:2000 includes season/month strings and repeated interleaved origin strides.
Bank1 and16 end gaps CROSS bank boundaries in the raw complement: both claims
were explicitly cut at2000, excluding the following bank's native JMP/header.

Small native-entry JMPs were followed to independently established Code/frame
stubs in effective contexts, then proposed separately by gap-control.py. Tiny
unselected VM branch/return tails are localized representation Data; all branch
words land on established VM Data. The13-byte fixedF9AA:F9B7 routine is complete
STX5206/STY5205/LDY5205/LDX5206/RTS with bounded two-input/two-output register
contract and independently bounded neighboring accepted native routines. No
hardware multiplication or observed call is claimed from those instructions alone.
