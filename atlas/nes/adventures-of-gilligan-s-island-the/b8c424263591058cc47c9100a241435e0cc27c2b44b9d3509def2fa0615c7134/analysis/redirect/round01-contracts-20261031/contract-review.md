This is an actionable handoff, not terminal exhaustion. All proposals remain Static, including untraced bytes in artificial runtime scenarios. The proposal audit has no instruction-boundary or code/data overlap. No map/state edits occurred.

Full current-source6081-instruction survey recovered371 JSR sites and199 context-distinct callee roots. Earlier static-calls.py only inspected regions whose entire length was3 and opcode20, missing calls within merged regions. This instruction-level survey is a changed method. Native JSR entry contracts, supported indirect dispatch and decoded control/data/stack semantics support code; legal decoding alone does not. Calls, roots, discoveries, per-entry reviews and code-proposals.json retain physical identities and execution contexts.

Bank-preserving proof rejects mapper writes, unresolved indirect writes, possible return-stack writes, stack-pointer mutation, indirect jumps, unproved calls and unmatched local pushes. Loops need not terminate: only continuation if a routine returns is claimed. Separate fixed-window ordinary-return proof allows bank changes while setting switch slots null on continuation. Never interpret that weaker proof as preservation of incoming switch banks. Old verifier outputs survive; failed proof is a missing method premise, not evidence against code/data or dead-code evidence.
