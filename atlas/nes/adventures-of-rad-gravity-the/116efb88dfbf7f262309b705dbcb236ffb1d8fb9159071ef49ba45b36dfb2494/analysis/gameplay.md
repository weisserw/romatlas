Manual transcription: https://www.world-of-nintendo.com/manuals/nes/adventure_of_rad_gravity.shtml (NES-2A-USA). Start opens Start/Continue; A confirms. On ship choose destination with D-pad and A; A again lands. On foot A jumps, B uses equipment, Start opens inventory, arrows select item. Communicator returns to ship and restores health.
