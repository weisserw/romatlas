Preserve code-review-before-bank-effects.json, review-initial.py and review-notes-provisional.md as historical provisional reasoning, not accepted evidence. The initial normal-return checker treated a mapper barrier as failure to return. This was a proof limitation, not a measured no-return result. An interim note incorrectly associated F14E with prior PLA/PLA atF14A: exact CPU decode shows F14E maps0D, loops through F312/F334/F3A5/F3EB, then F170 INC55/F172 RTS. F14A belongs the earlier F104 collision contract. That premise is superseded.

Final review uses a normal-return relation with effective output bank vectors. D085 loads0D then callsFB78 and returns after property lookup; under supported stage0/1 precondition0D=1 the output8000-slot bank is1. F14E uses the same mapper precondition; this changes caller context rather than forbidding all continuations. E80A loads immediate12 and maps it. The graph substitutes bank1 or12 at exact FB78 call sites with these byte-derived parameter contracts and propagates returned vectors through wrappers. It does not preserve stale slot0 values. Stages with0D3/5/7 remain valid independent roots from prior evidence; a single supported static stage-bank1 contract suffices for structural caller code.

E8D0 and bank11 B676 each save old1A into0591, map12, read animation and restore0591 before RTS. An ordinary return with initial nonzero frame-duration preserves incoming banks. Their zero-duration restart jumps to their own entry and can overwrite0591 with12, so bank preservation is a stated nonzero-frame precondition, not a universal claim about recursive animation redirects. This is enough to establish a supported ordinary return alternative; other outputs are not inferred globally.

Conditional discard paths (F110/F14A, BAC7, B1E9, B22F, EEB5,8294) remain code. Negative local stack depth never supports an ordinary return relation. Exact normal paths elsewhere may support caller code without claiming all branches return to that caller. Remaining indirect or mapper-blocked call returns are not inferred without a contract.
