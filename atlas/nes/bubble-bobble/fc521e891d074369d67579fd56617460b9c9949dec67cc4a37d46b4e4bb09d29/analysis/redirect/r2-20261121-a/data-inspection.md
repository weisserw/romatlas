# Residual noncode inspection

The combined proposal adds 4,586 Data bytes. Exact individual intervals, roles and evidence are in proposals.json. All are Static; no natural selection or new fetches are asserted. Practical reference, consumer and boundary inspection is saved in data-primary.json, data-primary2.json and data-primary3.json, with raw bytes and contextual instruction references. The generic fallback does not assert the original serializer, complete selector domain or every internal table subdivision.

The first group contains 22 pure residual lookup/OAM/text blocks (1,007 bytes) between independently supported Code boundaries. They include boss palette rows, four sprite-frame records selected by frame bits, boss body tile/coordinate patterns, actor motion deltas, sprite-pointer/triplet bodies, terminal $80 motion sequences, score thresholds, player/companion OAM templates, finite vertical motion steps, tile/attribute pairs and stage pacing/CHR selectors. Accepted consumers read these bytes into motion, OAM, palette or mapper-value fields. Repeated values and record vocabulary support noncode even when a whole selector domain is unresolved. F64A..F72E is three adjacent tile/attribute domains read by F383, A42F and 96A8; no original subdivision beyond those known origins is required.

A second group splits clear data subintervals from formerly mixed gaps: projectile/boss velocity values, little-endian image/map pointers, finite actor sprite templates, item/score selectors, decimal/pattern values, PPU coordinate/field records, map RAM source words, and the ten password alphabet tiles. The alphabet has independent decimal digit handlers bounded by 0..9, the FDA1 table and the next FDAB code boundary. The generic clauses retain their mechanical consumer explanations without inventing an actor/item identity.

The connected ending graph supplies bank 10 $8C07..$8D75 lookup/record bodies, $8D95..$8F67 credits glyph/text sequences, $9713..$9747 coordinate/OAM/tile patterns and $989B..$98C7 eleven OAM records. Raw credits tiles visibly encode PROGRAMMER, CHARACTER, SOUND, PLANNER and names interspersed with sequential glyph strips; dynamic record-pointer consumers were checked. Specific full credit-record extent semantics are not needed to classify their visibly non-instruction bytes. The fixed C2A6..C2F3 title/copyright glyph bytes similarly form bounded repeated tile and letter sequences between reviewed code. F540..F560 and F239..F249 are repeated four-byte OAM patterns. No executable flow crosses these intervals.

Two independent larger source contracts improve upon a pattern-only fallback. Bank 10 $999C contains $99AA; the $993A renderer copies exactly 25 rows of 32 tile bytes, ending at $9CCA, replacing zero tiles with $0494. Twelve preceding bytes are copied to palette RAM independently. Initialization C1B6 calls F992 in mode 0 with 28 blocks, two eight-byte copies per block and inline source FACE, proving exactly 448 bytes through FC8E. C1C4 uses the same consumer with two blocks and source C1E5, proving 32 initial palette bytes. The title rows also have conspicuous 32-column blank/tile vocabulary. No stronger original container claim is made.

New inline words use the existing nested F922/C4C3 stack-reader contracts, plus F992's identical outer-frame reader. The eight FEDA return words are independently bounded by FE32's X=0..7 scan, doubling and synthetic RTS dispatch; following FEEA..FEF3 is a separate nine-byte cursor tile pattern. Remaining FA04 immediate-Y and FA13 nonzero header-nibble source spans are recorded in ppu-source-extents.json and proposed only to the exact Unknown portion of their unions. Each copied block was also checked for visible noncode vocabulary; a copy alone was not treated as a universal data proof.

The two isolated six-byte sound-disable candidates and two-byte word C1E3 remain unclaimed: the former lack an independent entry/flow contract, and the latter is an unreferenced apparent FACE pointer adjacent to the proved palette. No automatic generic fallback was applied to these ambiguous tiny islands. The exact 142-byte residual and other short instruction-like fragments are recorded in unknown-ledger.json.
