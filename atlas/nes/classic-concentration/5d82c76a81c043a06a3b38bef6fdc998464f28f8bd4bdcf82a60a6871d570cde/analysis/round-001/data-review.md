## Fixed-bank code

The bounded custom traversal stays entirely in the invariant $C000–$FFFF physical windows, follows direct branch/jump successors and callee entries, and deliberately stops every JSR fallthrough. This avoids interpreting return-address-driven inline data as code. The toolkit's discover_context remains more conservative at mapper writes and calls; this local fixed-window rule is safe for mapper 2 because these physical slots do not change. ## Inline screen records
Consumer $FBFC pulls the JSR return address into $08/$09, retains cursor/control state, then iterates the inline stream. Coordinates/control occupy the first two bytes; zero terminates the glyph/control stream; $0D is newline and $FE references dynamic text. These records were annotated only where a supported call anchors the start and a bounded zero terminator anchors the end. Generic Data represents the mixed control/text record, with ScreenRecord labels. The separate $C921 graphics descriptor and $C997 variable records remain unresolved barriers; no automatic return continuation was assumed there.
