# Narrow pointer/mapper refinements

These are supported entry preconditions, not claims of arbitrary initial-state safety. No mapper/indirect-write opcode is globally allowed.

- Sound helper $DA0F..DA3B, physical bank14, destination ($1E),Y: all direct calls in StartSong and its fallthrough set $1E/$1F from fixed words $DB2C/$DB2E/$DB30. Those are $03A0/$03B8/$03D0; Y stores explicitly visit fields0..4. Destinations are RAM $03A0..03D4, cannot overlap stack or mapper. The helper does not change its destination pointer. This permits RequestSound's ordinary-return proof; it does not establish all sound engine indirect stores safe.
- Text queue $E79E..E80F initializes $10/$11=$0500 internally. Every indirect destination is ($10),Y, with Y an8-bit index and the pointer unchanged, so stores are confined to $0500..05FF. Queue overflow/semantic correctness remain separate from mapper/stack safety.
- QueueTileColumn/AttributeColumn/TileRow/AttributeRow at $F66C..F7E1: callers establish $12/$13=$0500, as source camera/edge builders show. Stores through ($12),Y remain in $0500..05FF, and helper bodies leave the base unchanged. Conditional contract only; arbitrary caller-supplied pointers are not safe. Every currently connected direct caller is a camera/edge queue builder establishing the base. A novel caller must revalidate this precondition.
- MMC1 CHR0/CHR1 five-write routines $E9EB..EA14 return with balanced stack and do not write PRG/control. This128KiB PRG/128KiB CHR mapper1 image does not require outer PRG address lines from CHR registers. Aligned serial phase is a supported game invariant (five-write sequences; reset initializes state).
- Mirroring helpers $E9C4/$E9CD change only shadow$C0 bit0. Reset supplies$1E, and the only maintained-source shadow writers are reset and these two helpers. Thus control bits1..4 remain$1E, PRG mode3 remains fixed, and five writes to$9FFF preserve all effective PRG slots. Arbitrary entry to the raw writer$E9D6 with arbitrary A is not claimed safe; the traversal only inherits it through these bounded shadow helpers.

Inline dispatcher$E333 and RTS trampolines remain barriers to ordinary-return proof. Source citations: maintained game.asm entries StartSong, QueueSceneTextBlock, QueueTileColumn/Row, WriteMmc1Chr0, SelectMirroringEven/Odd and InitializeSession. Official decoder artifacts retain physical instructions; proposed contracts are Static and need independent disassembly review.
