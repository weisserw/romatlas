# Round002 redirect static contracts

These are proposals, not annotations. `ready-proposals.json` contains exact unknown instructions/ranges and execution views. `final-validation.json` checks all byte collisions and saved actual-fetch starts. All proposed code is Static by default; `observed-roots.json` separately supplies actual artificial-scenario fetches for independent review. Legal decoding was checked after role/entry/control contracts, not used as their sole basis.

- **Fixed public services:** 55 three-byte JMP entries C000..C0A2, bounded by actual C0A5 worker. Most entries already have accepted callers and routine contracts. `fixed-public-graph.json` follows the remaining entries and fixed continuations, including pointer/PPU conversion, arithmetic, UI, resource and shared helpers. Fixed storage stays banks30/31 across mapper selection. Lower-window calls stop unless an independently established entry contract resolves them. The prompt span DF16..DF27 is an explicit data barrier; flag-infeasible fallthrough is never promoted.
- **Audio:** `audio-ui-graph.json` includes ordinary channel-state/envelope/period continuation fragments from accepted audio entries. AF39 is a recognizable copied UI initializer: same known bank22 AECB PPU/window/menu setup, with independently decoded palette operand9DC0 rather than9DB6; adjacent CR/00 supplies the local body boundary. Followed helpers preserve scratch/stack, manipulate menu/cursor/RAM state and return coherently. This supports stored code, not a claim that this bank's copied UI or palette assets form an ordinarily selected game route. All paths decoded officially with no data/BRK stops.
- **Travel/arena and town/archery:** `entry-20-graph.json` and `entry-22-graph.json` start from accepted fragments plus the fixed callers in `entry_contracts.json`. Arena setup/action/score continuations, riding controls, wrapping town coordinates, minigame result paths and associated arithmetic/formatting helpers have coherent RAM/control flow and ordinary local calls. A successful runtime victory/hit is not required for their static role, and is not claimed.
- **Save/menu/sprite services:** `entry-26-graph.json` includes the C8AB explicitly bank-selected8006 menu/storage interface, SRAM record/page/checksum processing, animation/OAM helpers and balanced return paths. PRG, SRAM, RAM and PPU spaces are separate; inspecting SRAM validation does not classify its nonexistent ROM backing as data.
- **Lock and maze:** `frame-28-graph.json` starts from accepted lock fragments, newly observed post-ring maze initialization and fixed Mode2/0E bank-selected8006 frame entry. Tool, spring/tumbler, trap/reward, room/player/object, PPU and timer continuations are followed through actual supported helpers. Ring/success/maze observations corroborate a subset. No arbitrary target address alone is a root. Relevant code routines save/restore scratch, explicitly consume their finite records and use normal returns or documented aborts.
- **Bank preservation:** local graphs have no direct mapper-register stores. Fixed random, wait, arithmetic, RAM/PPU/window/text services preserve PRG selection. Graphics/screen loaders and F06D character-script service save/restore requested selection; NMI commits that request. A bank selected by a fixed wrapper uses physical8KiB indices `[2*n,2*n+1,30,31]`; mapper values are never substituted for physical indices. Inactive copied helpers have external callbacks explicitly unresolved, not silently traversed.
- **Copied helpers:** `shared-library-review.json` validates all20 blocks against accepted tavern code. Opcode, length and every instruction boundary match; every changed operand is a -1 address relocation, including two split immediate pointer lows. External callbacks may overlap accepted Text in inactive copies. This limits callability/reachability, not recognition of the stored relocated machine code. Data islands and22-choice streams are separately validated; no Text is retyped.
- **Copied renderer/producer:** `copied-renderer-review.json` has four byte-identical577-byte B3A7 renderer/scratch bodies, independently decoded in each bank view. `copied-ppu-producer.json` contains a34-byte exact same-origin pending-PPU producer copy. Known control/stack/PPU contracts, repeated code identity and exact body boundaries support the role; no natural caller assertion.
- **Reset stubs:** `reset-contract-review.json` uses lower alias BFD8 with mode3 lower selected pair and fixed upper30/31. INCFFD7 resets MMC1 control without changing PRG selection, so this lower alias retains its physical continuation. A pending NMI initially preempted the probe; the improved probe waited for RTI and then confirmed the three actual lower-stub fetches through C000. Upper alias continuation from an old nonfinal pair is expressly not claimed.

Connected graphs have no pending local frontier, unofficial-opcode/BRK stop, data collision or alternate overlapping instruction decoding.
