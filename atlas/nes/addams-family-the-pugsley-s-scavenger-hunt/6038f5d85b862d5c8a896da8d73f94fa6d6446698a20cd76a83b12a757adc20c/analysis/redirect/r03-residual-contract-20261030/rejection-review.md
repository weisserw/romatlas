## Descriptor-tail returns:01A72E..01A72F,01A737..01A738,01A79C..01A79D (3 bytes)

Candidate: Static Code RTS closing an object initializer. Independent constraints together: five-byte descriptor headers establish exact initializer entries A71B,A724,A789 in banks12/13; each accepted three-byte JMP tail-calls the shared initializer; adjacent headers/behavior establish the next physical boundaries. [source-flanks.txt](source-flanks.txt) shows all three and the neighboring A792 thunk which does not have the extra RTS. [low-type-descriptor-table.json](../r02-contract-20261030/low-type-descriptor-table.json) and current annotated header regions provide the consumer/entry basis.

The JMP removes local fallthrough. Its target returns to the descriptor loader using the inherited return address, not to JMP+3. Thus the established stack contract supports the JMP but supplies no role for the following60. This rules out a *necessary reached epilogue under that contract*, not an independently entered empty function or syntactically retained unreachable RTS. Strongest alternative: an assembler's redundant return after a tail-call versus padding between separate records. Both yield exactly the same bytes/boundaries, and neither has an independently bounded macro/record contract selecting its role. A second caller is not universally required; here the actual accepted contract fails to include the byte. Generic Data is also insufficient: one legal return at this specific routine boundary is materially unlike the neighboring five-byte descriptor structure. Retain Unknown. Running the known initializer again cannot discriminate these hypotheses.
